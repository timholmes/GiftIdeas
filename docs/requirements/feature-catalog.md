# Feature Catalog (User-Facing)

## Purpose
Capture what product features exist today in plain language.

## Audience
- Product
- Design
- QA
- Stakeholders who want a quick feature inventory

## Scope Rules
- This document lists user-facing capabilities only.
- This document intentionally avoids technical requirements and implementation details.

## Status Legend
- Built: available and usable in the app now
- Partial: visible in the app but not fully complete
- Planned: called out as intended but not implemented yet

## Built Features

### 1) Sign In and Sign Out
Users can sign into the app and sign out when they are done.

### 2) Local Test User Sign-In
In local development, users can quickly sign in as predefined test personas.

### 3) My Ideas (Core Idea Management)
Users can:
- View their idea list
- Add a new idea
- Open an existing idea and update it
- Remove an idea from their list

### 4) Connections
Users can:
- Add a connection using email
- View current connections
- Remove a connection

### 5) Main App Navigation
Users can navigate with dedicated tabs for:
- Home
- My Ideas
- Give
- Connect

## Partial Features

### 1) Give
A Give area exists, but the user flow/content is not complete yet.

### 2) Sharing Flow from Home
The Home screen points to a sharing action, but this flow is not fully wired end-to-end.

## Planned Features

### 1) View Others' Ideas
This is identified as a desired feature and is not complete yet.

## Suggested Product Framing
This product currently delivers a working personal gift-idea tracker with basic connection management, while collaborative sharing and viewing others' ideas are still in progress.
